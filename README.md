# Pronostico-de-demanda-electrica-en-Ecuador
Sistema de pronóstico de demanda eléctrica en Ecuador mediante modelos autorregresivos y redes neuronales recurrentes. Este repositorio contiene el código fuente, datos y cuadernos de experimentación desarrollados para el Trabajo de Titulación de Ingeniería en Ciencias de la Computación en la Universidad Politécnica Salesiana, Sede Guayaquil.
